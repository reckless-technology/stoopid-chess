# The match and self-play tools, pinned: tools/setup-dev.ps1 -Tuning and tools/setup-dev.sh --tuning install them
# under ~/tools (%USERPROFILE%\tools on Windows), and tools/match.*, tools/selfplay.* and tools/spsa.py look for them
# there. One line a download:
#
#   tool  version  platform  executable  download  sha256  url
#
# The executable and the download are paths under ~/tools; an archive is unpacked beside itself and kept, so its
# SHA-256 says the version in place is the pinned one. The SHA-256s are the digests GitHub publishes for the release
# assets. A platform with no line for a tool has no release binary of it: pawnstar has none for Intel Macs, Linux on
# arm64 or Windows on arm64, where it is built from its source (github.com/reckless-technology/pawnstar) and passed
# to tools/match.* as --opponent.
